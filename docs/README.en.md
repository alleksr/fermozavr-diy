# Fermozavr DIY documentation

[Русский](README.md)

This is the project's brief technical documentation. Project essays and updates are published on [Fermozavr](https://fermozavr.ru); these pages collect information needed to run the station and repeat experiments.

## Sections

- [Station](station.en.md) — running the local page, receiving readings, and recording from an ESP32 over USB, Wi-Fi, or Bluetooth.
- [Readings and decisions](measurements.en.md) — data format, accuracy, and limits on conclusions.
- Hardware, schematics, and parts list — to be added after node testing.
- Test protocols — to be added as repeatable experiments are ready.

The page and server source code is in `station/`. This documentation describes the current implementation; requirements and hardware may change as tests progress.
