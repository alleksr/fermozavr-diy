# Документация Fermozavr DIY

[English](README.en.md)

Это краткая техническая документация проекта. Статьи и дневник проекта публикуются на [Фермозавре](https://fermozavr.ru); здесь собраны сведения, нужные для запуска и повторения экспериментов.

## Разделы

- [Станция](station.md) — запуск локальной страницы, приём показаний и запись с ESP32 по USB, Wi‑Fi или Bluetooth.
- [Показания и решения](measurements.md) — формат данных, точность и ограничения выводов.
- Конструкция, схема и перечень деталей — появятся после испытаний узла.
- Протоколы испытаний — будут добавлены по мере подготовки повторяемых опытов.

Исходный код страницы и сервера находится в `station/`. Эта документация описывает текущее состояние кода; требования и оборудование могут меняться по результатам испытаний.
